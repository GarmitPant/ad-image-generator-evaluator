# AI Tool Declaration

This project was created using AI coding tools under human direction.

- **Claude** was used to codify the problem scope, conduct research and implement the system.
- **Codex** was used to assist with design decisions, implementation planning and specification creation.

The tools were given clear instructions defining their responsibilities and handoffs. The major design decisions originated from the human author, Garmit Pant, who directed the project’s scope and approach. AI tools helped develop and implement those decisions.
